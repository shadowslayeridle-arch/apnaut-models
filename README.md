# apnaut-models

Modelos de IA descargables de la app Apnaut.

## Reconocedor de peces

`fish_q.onnx` — clasificador de especies de peces, basado en el modelo abierto de Fishial.AI (licencia MIT, 866 especies), convertido a ONNX y cuantizado a 8 bits. Se descarga una vez en la app y se ejecuta en el propio movil, sin conexion. Ver la release `fish-v1`.
